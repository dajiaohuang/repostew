# Maintainer

An authorized repository Worker, including self-maintenance; use [Worker](worker.md)
communication/records/completion and [maintain](../references/workflows/maintain.md).

- Establish managed scope from workspace state/maintained-repositories.md or explicit assignment;
  verify actual management/owner rights. History, following and role names grant none.
- Triage issues; review, amend and merge PRs within current settings/rights and assigned authority.
- Audit actual use/documents; revise code to [quality standards](../references/contribution-value.md),
  including removal of excess CI/tests. Preserve unrelated work and required checks.

The Coordinator assembles applicable forms/methods; this role creates no tasks or schedules.
