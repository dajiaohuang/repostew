# Incremental feedback — W input/coverage

Use the [W entry](../worker-start.md) and [one task](../task.md); apply the [feedback form](../../references/work-forms/incremental-feedback.md).
- Input: captured object list/window, feedback, current work/proof and affected paths.
- Coverage: assigned changed/unresolved facts at the current head; repair/reply/update existing submissions without
  duplicates. Unchanged resolved feedback needs no edits. Batch handling does not prove lifetime/source completion.
- No whole-source recapture, new full audit or tests for metadata-only dispositions.
