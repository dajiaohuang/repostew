# New repository — C input/coverage

Use the [C entry](../coordinator-start.md) and [one task](../task.md); apply the [new-audit form](../../references/work-forms/new-repository.md).
- Input: selected native identities/aliases, exclusions, existing records and actual writers.
- Coverage: bounded [suitability](../../references/suitability.md) screening, evidenced skips and pending unknowns;
  each eligible repository gets one complete W. No clone/tests/pre-audit or proven-bug admission gate.
- Finish: whole selection accounted for under new-repository membership gates, not one batch finished.
