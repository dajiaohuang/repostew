# Open-object patrol

1. Enumerate authored/commented open issues, authored open PRs, and every authoritative container-root
   unfinished link, including nonmembers and closed/merged-but-unfinished objects. Exclude source/temp/
   archives; navigation is not complete scope. Split capped searches; report gaps, never empty-by-failure.
2. Inspect compact live state/head/CI; updated_at alone cannot prove unchanged checks. Deepen changed,
   unknown or feasible unresolved handling only; reuse evidence, check changed blockers, fetch missing facts.
   No repeated threads/tests/audits/clones or persisted interaction/CI registry.
3. Apply [necessity](../contribution-value.md) and scoped [reassessment](../reassessment.md); preserve genuine
   discussions, fix useful work, withdraw only within authority. Retain blockers/retry; remove only resolved entries.
4. Share the existing serial notification stream; deduplicate and finish an unfinished pass before another.
   No mail rescan/all-old new-issue expansion, parallel same-repository writer or resumed paused jobs.
   Configured cadence is not coverage/completion; archives never supply runtime state.
