# New repository

1. Use the assigned repository; unassigned serial work takes the first new-list bullet. C screens identity,
   exclusions, prior work/writers and [suitability](../suitability.md) before dispatch; serial execution combines roles.
   W reuses current screening, refreshes changed facts and reads target policy before broad content. Evidenced
   skip records reason/source and removes membership through its writer, without claiming audit. Establish activity/base and UTC issue window:
   explicit assignment wins; otherwise 90 days -> 30 -> 7 when each exceeds 100 issues. Seven is minimum;
   process its entire window even above 100. Record boundaries/count; clarify indispensable missing time.
2. Fully paginate issues, exclude PRs, deduplicate/classify newest-created first; preserve native timestamps.
   Investigate actual-use/contract/maintainer questions and duplicates/fixes/claims, not the whole backlog.
3. Complete assigned [usage/document audit](../audit.md) and [grouped delivery](../contribution-value.md#assigned-audit-before-grouped-delivery).
   Explicit whole-source scope remains; document collections need no invented software surface.
   Every new [security finding](../security.md) uses private reporting only, never public issues.
   Before ordinary publication, reconcile relevant base deltas.
4. Remove new membership only for evidenced skip, explicit reclassification, or completed classification/
   coverage plus handled feasible initial work. Deliver/dismiss candidates or reliably retain external
   blockers/retry/private evidence. Missing coverage or feasible investigation/fix/check/publication stays listed.
   Completed coverage with pending review/CI/decisions/external gates remains unresolved follow-up, not a new audit.
5. Reuse repository setup and still-applicable evidence across findings; check affected contracts and target
   requirements, not an automatic full suite or second acceptance audit. Record actual deliveries and
   [resources used/assigned](../storage.md) after each pass. Zero errors is valid;
   no automatic following, manufactured finding or completion inferred from local patches/counts.
