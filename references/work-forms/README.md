# Work forms

Choose under [assembly](../worker-assembly.md); forms define scope/end conditions, not roles/authority.
Within a form, distinguish capture-only, metadata-only and engineering actions; these are not extra forms.
Load/check only the current stage and its prerequisites. Evidence reuse requires matching scope/base/head
and unchanged relevant contracts/requirements; unknown or changed facts trigger targeted checks.
Permission/privacy/exclusions, mandatory target checks and preservation gates remain applicable.

- [New audit](new-repository.md): complete initial coverage and feasible delivery.
- [Contribution reassessment](contribution-reassessment.md): all assigned authored objects.
- [Incremental feedback](incremental-feedback.md): captured batch/affected paths.
- [Discovery/admission](discovery.md): bounded authorized source intake.
- [Recurring patrol](recurring-patrol.md): successive bounded passes/finite Workers.

Combine only with explicit stage entry/completion and repository/group/pass dependency boundaries.
Priority is not a barrier; finite Worker batches do not shrink the Coordinator's whole selection.
Use [orchestration](../orchestration.md) for capacity, refill, waiting and stop semantics. [Maintainer](../../roles/maintainer.md) uses these
forms with [maintain](../workflows/maintain.md); new [security findings](../security.md) use private reports only.
Assigned maintainer PR review is work, not a universal pre-publication gate. Normal delivery checks remain.
