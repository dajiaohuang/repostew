# New-repository audit work form

Input: repository, base/window, prior work, authority/resources; membership never erases history.
Load [workflow](../workflows/new-repository.md), [suitability](../suitability.md), [audit](../audit.md),
[contribution rules](../contribution-value.md), [delivery](../workflows/delivery.md) and required safety/records/storage.
Complete classification/coverage before grouped delivery; explicit whole-source scope remains.
Coordinator removes membership only under workflow gates; missing coverage/feasible work stays listed.
Retained external follow-up remains unresolved; zero findings is valid. Report coverage/outcomes/resources separately.
