# Discovery and admission work form

Input: authorized sources/scope, filters, membership/identities, any explicit shared-list write window.
Load [discovery](../workflows/discovery.md), [suitability](../suitability.md), workspace/records and scoped target rules.
Extract identities, lightly screen/deduplicate; Coordinator appends or grants bounded append window.
Batch identity/exclusion/membership checks for the finite selection; query ambiguity, not every known name.
No pre-admission engineering audit/checkouts/tests, PR gates or empty project records.
Report coverage/additions/skips/errors, including zero. Admission is not audit/following/public authority.
Apply storage only to resources used or assigned; no no-resource proof ceremony.
