# Existing-contribution reassessment work form

Input: native repository/author, whole or explicit object set including earlier submissions, exact action authority.
Load [reassessment](../reassessment.md), [contribution rules](../contribution-value.md),
[delivery](../workflows/delivery.md) and required safety/records/storage. No default new audit/acceptance review.
Capture all assigned objects, disposition each, finish feasible repair/consolidation/authorized withdrawal.
Preserve discussions, blockers/retry, merged/others' work. No automatic membership/position effects.
Use [history](../workflows/history.md) only for requested recovery/reclassification.
