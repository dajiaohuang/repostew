# latitude-dev/latitude-llm

Lessons distilled from October 2026 feedback. Apply only to SDK-source contributions;
recheck current generation inputs and contribution policy. These are not current PR
status or maintainer authority. See the [reference scope](../README.md).

- The SDKs are generated from the API/OpenAPI surface. Hand-edited generated SDK
  output will be overwritten and is not accepted for merge. For a valid behavior fix,
  locate and change the authoritative API/OpenAPI or generator input, regenerate the
  SDK, and preserve the corresponding issue for maintainer routing when that source
  is outside this repository. Do not reopen equivalent direct SDK edits. [Maintainer
  feedback](https://github.com/latitude-dev/latitude-llm/pull/4809#issuecomment-5990610829);
  same direction in [#4811](https://github.com/latitude-dev/latitude-llm/pull/4811#issuecomment-5990610570),
  [#4813](https://github.com/latitude-dev/latitude-llm/pull/4813#issuecomment-5990610282),
  and [#4815](https://github.com/latitude-dev/latitude-llm/pull/4815#issuecomment-5990609963).
