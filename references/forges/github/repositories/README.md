# Repository and organization references

Read only the applicable repository or organization reference for the assignment.
Repository rules live in `<owner>/<repo>.md`; organization-scoped rules live in
`<owner>/README.md`. Target lists, batch thresholds, submission restrictions and
target-specific implementation or validation requirements stay here, outside shared
policy and the common dispatch prefix. Preserve their exact scope and source;
reading a reference does not select targets or authorize execution.

Feedback lessons were distilled from the authorized private feedback archive
in October 2026; repeated messages are consolidated by direction, not copied as transcripts.
Public source links retain context. Raw interactions remain in their authorized private archive.

Engineering review advice is evidence to evaluate, not a grant of maintainer authority.
Questions, optional suggestions, revision requests, rejected approaches and temporary
submission restrictions have different scope. Recheck current policy, assignment,
canonical source and supported versions before acting; never infer a permanent or
repository-wide ban from a narrower reply. Shared principles live in
[safety](../../../safety.md#feedback-derived-review-rules).
