# domokane/FinancePy

Lessons distilled from October 2026 feedback. Apply only to the stated direction;
recheck current contribution policy and volatile facts. These are not current PR
status or maintainer authority. See the [reference scope](../README.md).

- Check/validation methods retain their established raising/void contract; the owner rejected adding return values. [Feedback #343](https://github.com/domokane/FinancePy/pull/343).
- Repair generated documentation in function docstrings or the canonical generator input, not only generated output. [Feedback #319](https://github.com/domokane/FinancePy/pull/319).
- Numerical fixes need a corresponding unit regression, including zero volatility where affected; source reasoning alone did not satisfy the cited review. [Feedback #317](https://github.com/domokane/FinancePy/pull/317).
- Provide a unit test for the reported defect using the actual library path. [Feedback #309](https://github.com/domokane/FinancePy/pull/309).
