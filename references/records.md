# Minimal records

## Record homes

- state.md: current native URL + next action/wait reason, minimal identity/base/meaningful coverage/resource facts.
  One object per line; replace superseded facts, remove only after resolution, omit empty/unknown boilerplate.
- work.md: one short dated line/native link per actual delivery/withdrawal/verified resolution; combine steps.
  Migrated links alone prove no date/result/history. Membership = names; unfinished.md = state links only.
- Preserve exact positions/aliases and unpublished/private evidence. Use the same assigned scope/base/coverage
  unit; read counts, inventory, migration dates and record compactness never prove audit completion.
  Classification does not adopt upstream backlog. Keep assigned/followed/captured work until handled/retained;
  feature wishes/refactors/product questions are not automatically repair tasks.

## Write and read only what changes the action

Write material action/constraint/coverage/delivery/resource changes only; no unchanged patrol/CI/slice logs,
parallel diaries or copied reports. One current home and one history line per actual delivery.
Read affected state and relevant live objects; history only for concrete questions. Reread after another writer,
skip occupied repositories, preserve unrelated/ambiguous data. Lossless Markdown/newlines; diagnose encoding
failures rather than silently replacing text. Separate coverage, contribution, resolution and resource facts.

## Feedback and evidence

Discussion/CI details stay native. Scoped [lessons](forges/README.md) include source; generalize only
shared principles. Recheck volatile restrictions; contributor association is not maintainer authority.
Classify revision/rejection/non-defect/takeover; stop equivalent rejected directions and reassess related objects.
Withdraw authored rejected PRs/false defect issues only within authority; otherwise retain action/reason.
Raw evidence only when requested/private/irrecoverable: one canonical copy, optional link/classification index,
no duplicated transcripts. Separate human/bot feedback; disclose skipped checks/component limits.
After delivery, use live native bodies/links, retaining unique evidence only; migrated drafts are not upload-ready.
Mail/security stay protected/unsynced. Advancing positions never resolves engineering work.

## Authorized migration

When requested, enumerate container-root records plus active global/private records, including nonmembers;
exclude source/temp/archives/unrelated data. Preserve native text/positions/aliases, unfinished/private findings
and safety/validation boundaries; remove repeats/superseded logs/empty templates only.
Read before edits; preserve intervening writes, defer occupied/ambiguous/undecodable records.
No inferred resolution/authority/delivery/deletion/coverage, recovery copy, permanent migration ledger or public
mutation/cleanup. Report actual migrated/deferred scope once.
