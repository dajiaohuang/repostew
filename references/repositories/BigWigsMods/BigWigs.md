# BigWigsMods/BigWigs

Lessons distilled from October 2026 feedback. Apply only when inferring supported
client versions from TOC interface entries; recheck current project policy. These are
not current PR status or maintainer authority. See the [reference scope](../README.md).

- Old interface numbers in TOC files are retained as templates for adding future TOC
  versions; their presence alone does not mean the addon supports those old clients
  or private servers. Confirm the maintained client matrix before adding compatibility
  guards or removing interface entries. [Feedback on #2810](https://github.com/BigWigsMods/BigWigs/pull/2810#issuecomment-5994276997).
