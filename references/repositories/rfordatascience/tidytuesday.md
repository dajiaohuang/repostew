# rfordatascience/tidytuesday

Apply these lessons only within the cited scope; recheck current policy before future work.
See the [reference scope](../README.md).

- Preserve actual newlines in public descriptions. The maintainer asked what assistance was used after repairing escaped newlines; answer factual disclosure questions truthfully, without guessing original tools or implying an executed rendering check. This question is not a contribution-method refusal. [Feedback](https://github.com/rfordatascience/tidytuesday/pull/1087#issuecomment-5953128605).
- Assignment-workflow behavior changes that support a new dataset shape need a real submission fixture demonstrating that shape; do not add code for a hypothetical format without one. The maintainer requested a separate dataset containing both R and Python cleaning scripts before testing the multi-script rendering change; no such concrete submission supported PR #1087, so it and issue #1086 were withdrawn. [Feedback](https://github.com/rfordatascience/tidytuesday/pull/1087#issuecomment-5993728350).
