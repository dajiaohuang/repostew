# Construct a Worker assignment

Role = responsibility; form = coverage/progression/completion; method = investigation/delivery.
Construct ordinary text using [templates](../prompts/README.md); no compiler or task protocol.

## Establish intent before choosing a template

1. Establish outcome, exact scope, prior work, authority/resources; never infer permissions.
2. Choose [form](work-forms/README.md) from assignment/native authored history; comments are not authorship.
3. Capture/deduplicate; normally one complete repository batch per engineering Worker,
   one bounded source batch for discovery. Resolve known writer conflicts before dispatch.
4. Select applicable methods and action limits: investigate, repair/deliver or authorized withdrawal.
5. Establish [harness capabilities](harness.md) and [native forge mapping](forges/README.md); retain blockers,
   never silently substitute exact execution settings.

## Compose the context

Order: [SKILL.md](../SKILL.md) + role + [orchestration](orchestration.md) -> selected form/methods
-> scoped target references -> task facts/overrides. Keep unchanged shared text stable.
Include workspace/records for state, safety for external changes, storage for repository passes,
contribution standards for engineering. Do not send every method to every Worker.
Task facts: workspace, native identity, objects/window/base, dependencies, authority/resources,
evidence, overrides, end condition and result delivery. Omit inapplicable fields/transcripts;
Workers establish ordinary unknowns; clarify indispensable missing scope/authority.

## Deliver authoritative instructions

Readable workspace: supply exact paths and require applicable reads before action.
Otherwise inline complete applicable current text with source labels; paths/summaries are insufficient.
Full current inline text satisfies reading. Reuse unchanged context; refresh policy/live deltas.
Resolve user/target/authority conflicts before dependent actions; preserve protected context boundaries.

## Combine stages without combining away their boundaries

State each stage's input/scope/output/permission/entry condition. Finish required reassessment
and feasible actions before new audits; reliable external blockers need not delay independent work,
but missing capture/feasible local work blocks refill. Keep stage coverage distinct.
Recurring Coordinators construct finite batches; cadence/activation belong to the scheduler.

## Dispatch, continuation and handoff

Check scope, authority, resources, dependencies, end condition and delivery once; dispatch once.
This is assignment sufficiency, not a code audit or added PR review.
[Continue](../prompts/continue.md) by delta with the same execution. Before
[handoff](../prompts/handoff.md), end the prior writer and reconcile uncertain mutations.
Retain unfinished work in repository state; native task IDs are transport handles, not claims/queues.
