Portable repository stewardship

把贡献做完。
把维护接起来。

一套直接读写 Markdown 的仓库维护 Skill：发现、处理 issue、审计、修复、验证、交付 PR，再持续跟进评审、CI 和未完成事项。不绑定执行器、模型供应商或操作系统，不需要额外运行脚本、数据库或协调服务。

从 README 开始 读取 Skill

名单选范围。
每库记录存事实。

三个成员名单

新库待处理、旧库历史全表、分组关注名单。名单只保存成员；关注组允许重合，扫描去重并集。

极简记录，按需回查

state.md 留当前待办和必要边界；work.md 每次实际交付一行。通用经验进入 skill 规则，逐库经验进入按需读取的 reference，附范围与来源。公共审查规则按相关契约应用，不扩大任务范围。实质变化才写，交互原文回原生来源或授权私密归档查，中央 unfinished.md 仅导航。

相对目录，源码可处置

工作区保留 RepoStew_skills/、state/ 和 work/owner/repo/。源码在 checkout/，释放源码不删除记录。

来源独立，隐私隔离

通知与关注扫描位置在 read-positions.md，邮箱位置在 private/。保留原生边界，正文实时读，不复制交互数据库。

一套交付流程。
两种指派范围。

获授权的 Trending、awesome 清单库及清单内项目，确认真实身份、贡献适配、既定筛选并去重后追加新库名单末尾，不提前克隆或审计。资源与 awesome 清单可做文档修复，仅在明确拒绝外部 PR 或禁止本次投稿方式时跳过。已有库接续原范围，不重置进度或自动关注。

有依据的不适合贡献新库记录原因后直接跳过；其余完整分类近期 issue，沿约定的实际使用和调用链查错，并核对真正的文档错误，不默认逐文件通读。完成约定范围后集中交付修复；明确要求全源码审查的任务仍按原范围完成。关注旧库只处理本批新 issue 和相关代码，不重复全审计、不改成员名单；没有新 issue 就不开 leaf。

固定本次范围与基线，提交前补查相关变化。审计覆盖与可推进初始工作完成后移出新名单；评审、CI、维护者决定或外部交付门槛保留待办和重试条件，不视为已解决，不重复整库审计。安全审计独立评估部署、攻击者能力、信任边界与安全影响；攻击者输入不必是正常用户支持的输入，发现与证据走私密披露流程。

默认串行，明确授权后才并行。轻量协调者抓取、去重、按库分派和补位；leaf 自行调查、修复、验证、投稿、释放，并直接写本库记录。协调者只更新共享名单、导航和位置，信任返回及已报告写入，不重复验收。同库单写入者；发现者直接追加时约定短暂写入窗口。

新 leaf 先接收固定顺序、保持一致的公共规则原文，再追加仓库、范围、授权与资源等任务信息；沟通与返回要求共用前缀。完整内联规则不重读，同库续办只传变化；规则改变才刷新前缀，目标政策和实时事实仍须核实。

先读目标政策，证明实际使用错误或可验证的现有文档错误，聚焦受影响检查与强制项，合并最终审阅；收益或更整洁的实现不能代替错误证据。PR 不强制关联 issue，有匹配项就复用和关联，否则在 PR 中说明错误证据，并遵守目标库明确要求。实际使用中有证据但需确认预期或方向的问题，开或复用讨论 issue；为继续调查所必需的具体问题可以提前提出，确认错误与修复方向后再提修复 PR。每库文档小错误集中到一个勘误 PR，已有开放勘误 PR 就继续补充。符合门槛优先普通 open PR；Draft 同样要求错误和修复方向成立。不强造投稿、不默认等 CI 或合并。缺少 issue/PR 结果就问原 leaf，仍可推进则继续；明确失败、矛盾或冲突才局部恢复。

外部贡献源码通过精确授权、交付和非占用门槛后，删除指定 checkout/temp 并记录操作结果。不新建恢复副本，不盘点独有或未知数据，不做删后核验或磁盘检测；保留已知未交付、占用及无关材料、永久记录和现有归档。自有库不适用，不清 Go 缓存或工具链。

及时接续。
低频兜底。

可配置 1／6／24 小时基线：每小时通知与选定邮件文件夹平级增量，各自位置、合并重复对象；每 6 小时完整抓取关注库新 issue，按库分派；每 24 小时全量找本人创建/评论的开放 issue、创建的开放 PR 和全部每库未完成链接。

优先共用现有巡检对话，上轮未结束就继续，不叠加。兜底先看状态、head 与 CI 概况，仅变化、未知处理或仍可推进事项深入处理；不重读整段讨论、重测或重克隆，也不只靠 updated_at 判断 CI 没变化。

只读选定邮件文件夹，不读其他文件夹、不发邮件、不改已读或订阅；实质回复在工程对象完成。完整抓取且处理或可靠保留才推进位置，失败不当空结果。无变化安静，仅进展、失败或需用户决定时通知。

周期与启停由工作区调度配置；Skill 不自动启动任务或恢复暂停计划，周期也不是完成时限。关注和历史贡献不授予维护权限。私密邮件、安全正文、凭据、源码及恢复材料不进入公开状态或备份。

Finish contributions. Continue stewardship.

A portable Skill with direct Markdown state, three membership lists and persistent per-repository records. No extra runtime service, database or required client/vendor.

One lightweight coordinator/leaf delivery flow: skip evidenced unsuitable new targets; classify assigned recent issues and audit agreed usage paths and documentation facts. Ordinary audits do not default to file-by-file reading; explicit whole-source assignments retain their scope. Security audits independently establish threat boundaries and impact with private disclosure. Followed batches cover their issues and affected paths only. Completed initial audits retain external follow-up without declaring it resolved or repeating the audit.

PRs need no separate issue; link matching issues and honor explicit target requirements. Evidenced actual-use questions needing maintainer agreement go to discussion issues; questions necessary to continue investigation may be raised earlier. Repair PRs, including Drafts, require established errors and intended corrections. Leaves own delivery and records; coordinators trust reported outcomes and react to concrete faults.

Fresh leaves receive identical current common policy in a fixed order before all assignment variables. Full inline rules need no duplicate reads; same-repository continuation sends only deltas. Refresh changed policy and verify live target facts.

Configurable hourly notifications/selected-folder mail, six-hour followed new issues and daily open-object fallback. Independent positions, deduplicated action, unchanged-work reuse and quiet runs. Schedules need explicit authorization; configured is not active or complete.

Authorized external source release keeps records and known undelivered/active material safe, without new recovery copies or post-delete disk checks. Self-owned repositories are excluded. Private sources and credentials stay private.
