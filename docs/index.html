Three membership lists

New targets, complete historical membership and followed groups. Lists hold identities only; groups may overlap, and scans deduplicate their union.

Minimal shared facts

Each project writer maintains root state.md and local work/work.md. Coordinator owns globals; only workspace policy/shared-state Git has a designated publisher. Repository Workers publish directly, one writer per project. unfinished.md is navigation only, not complete scope or authority.

One project, one directory

Use state/repositories/<host>/<namespace>/<repo>/. Share reviewed state.md; ignore local work/ with notes, multiple checkouts and tmp. Never recursively upload or scan execution material as state.

Independent, private sources

Public source positions live in read-positions.md; mail positions stay private. Preserve native boundaries and read source bodies live, without copying an interaction database.
