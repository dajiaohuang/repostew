# New repository — W input/coverage

Use the [W entry](../worker-start.md) and [one task](../task.md); apply the [new-audit form](../../references/work-forms/new-repository.md).
- Input: repository/base, assigned issue window or workflow default, screening facts and prior work.
- Coverage: classify the assigned issue window and complete actual-use/code/document audit; zero findings is valid.
- Deliver independently proved complete repairs without waiting for unrelated audit work; retain remaining coverage.
  Initial coverage is distinct from later review/merge. No investigation-only finish for an engineering unit.
