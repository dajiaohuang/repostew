# One task, five fields

Assign the complete authorized outcome, not a proposal awaiting approval. Do not add
routine “inspect then ask”, “report before continuing”, or C/S confirmation steps.
Workers apply [autonomous execution](../references/worker-autonomy.md): decide and act
within scope; request only an exact fact or owner action they genuinely cannot supply.
Explicit inspection-only tasks and real user/target restrictions retain their scope.

Use the [C contract](../roles/coordinator.md) or [W contract](../roles/worker.md), current SKILL and only
applicable methods/target rules. Supply complete current text or accessible exact paths once; variables last.
The selected [form](../references/work-forms/README.md) contributes input and coverage differences only.

> **1. Object and outcome:** {native project/objects/window or C's whole selection; expected delivery; form}.
> **2. Location and prior work:** {workspace, exact project state/work/cwd paths, base/head, writer, usable proofs}.
> **3. Complete TODO:** {remaining investigation/repair/target-required tests/direct submission/feedback; prepare the test environment only when the target requires tests; for C, select/assign/record/refill}.
> **4. Authority and resources:** {allowed destinations/actions; actual prohibitions/dependencies; task-owned paths, whole-unit estimates and actual user/platform limits, consumed amounts; C routing/capacity/source authority when relevant}.
> **5. Finish and return:** {code PR/MR: only “已投稿” and the link, then return capacity; no finding or cannot continue: short reason and return capacity; explicit non-code/local-only tasks retain their own deliverable}.

Ordinary contribution work includes direct submission, not permission to investigate only. C resolves indispensable
scope/authority/path gaps before dispatch; W resolves ordinary technical unknowns inside the unit. Missing
fork/head is a step. Do not copy global briefs, unrelated incidents or per-command budgets into these fields.
Explicit capture/inspection-only assignments state that limited outcome in field 1; never infer it from a frozen
source window or an engineering obstacle. Templates grant no new authority, schedules or shared-toolchain rights.
