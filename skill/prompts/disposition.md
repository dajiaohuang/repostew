# Authorized disposition execution unit

Use the existing authorized execution owner and the single [five-field task](task.md), not a second task sheet.
C only routes the unit and records ordinary outcomes; C neither approves nor executes deletion. Private
disposition is handled directly by its Worker without a C report or approval step.
Input: finite native projects/resource paths, explicit loss acceptance, existing records and stopped-writer handoffs.
Outcome: execute [minimal retention](../references/storage.md#minimal-retention-campaign), not merely inventory.
Keep state.md/work/work.md and protected exceptions; record abandonment, actual deletion, failed/retained targets.
No engineering, publication, backup, new timer or wider discovery. Continue independent eligible targets after local failures.
