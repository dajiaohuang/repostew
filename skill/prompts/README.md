# Prompt assembly and templates

Use [assembly](../references/worker-assembly.md) for context selection and ordering. Templates carry task
variables, not copied policy, executable protocol or authority. Use one C/W role contract and the single
[five-field task](task.md); one form below adds only input/coverage differences. Never stack task sheets.

- [Supervisor](supervisor-start.md): optional governance handoff and explicitly authorized heartbeat.
- Role entries: [Coordinator](coordinator-start.md), [Worker](worker-start.md); both use the same task sheet.
- New repository: [C](new-repository/coordinator.md) / [W](new-repository/worker.md).
- Contribution reassessment: [C](contribution-reassessment/coordinator.md) / [W](contribution-reassessment/worker.md).
- Incremental feedback: [C](incremental-feedback/coordinator.md) / [W](incremental-feedback/worker.md).
- Discovery + new repositories: [C](discovery/coordinator.md) / [new-repository W alias](discovery/worker.md).
- Recurring patrol: [C](recurring-patrol/coordinator.md) / [W](recurring-patrol/worker.md).
- [Disposition](disposition.md): temporary C for an explicitly authorized finite minimal-retention campaign.
- [Continue](continue.md): same-task delta/correction with suitable context.
- [Handoff](handoff.md): unit-boundary transfer after stop and mutation reconciliation.
- [Temporary reinforcement](reinforcement.md): scoped supplement for anomalies/delivery gaps, not a standing domain;
  [offline transport guards](transport-guard-reinforcement.md) specialize capture/limit/reader faults without resuming stopped units.

## Canonical context and ordering

Supply current accessible instructions or complete applicable text, not inaccessible paths/summaries.
Leaves receive their boundaries, not global briefs. Clarify indispensable scope/authority; Workers establish
ordinary unknowns. No credentials/private bodies/unrelated transcripts. Use [harness](../references/harness.md)
transport; templates neither launch tasks nor activate schedules.
