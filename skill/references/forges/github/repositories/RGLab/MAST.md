# RGLab/MAST

Apply these lessons only within the cited scope; recheck current policy before future work.
See the [reference scope](../README.md).

- Provide executed reproducible examples and concrete usage impact/prioritization before pursuing the cited batch of behavior changes. The maintainer is concerned about unknown reverse dependencies in this long-lived package; a source-only observation does not establish that compatibility cost is justified. For documentation/behavior discrepancies, discuss correcting documentation before adding behavior. This is a scoped review requirement, not a blanket outside-contribution ban. [Feedback](https://github.com/RGLab/MAST/pull/203#issuecomment-5959026239).
- Without a concrete use case, withdraw equivalent behavior changes whose benefit cannot justify that compatibility cost; do not fabricate usage motivation. Reconsider only with executed reproduction and a clear supported use case.
